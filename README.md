## Data Sources and Attribution

This project uses publicly available datasets from the following U.S. government agencies:

- **U.S. Census Bureau:** American Community Survey (ACS) 5-Year Estimates, 2019–2024. [Source](https://www.census.gov/programs-surveys/acs)
- **Bureau of Labor Statistics (BLS):** Local Area Unemployment Statistics, 2019–2024. [Source](https://www.bls.gov/lau/)
- **Bureau of Economic Analysis (BEA):** County Gross Domestic Product, 2019–2024. [Source](https://www.bea.gov/data/gdp/gdp-by-county)

### U.S. Census Bureau API Disclaimer

This product uses the Census Bureau Data API but is not endorsed or certified by the Census Bureau.

The Census ACS data used in this project has been cleaned and transformed for academic research purposes. The resulting datasets are team-processed derivatives and should not be represented as unmodified Census Bureau publications.

Bureau of Labor Statistics Attribution

The unemployment data used in this project has been cleaned and transformed for academic research purposes. The resulting dataset is a team-processed derivative of publicly available BLS statistics.

The Bureau of Labor Statistics is acknowledged as the original source of the Local Area Unemployment Statistics data used in this project.
